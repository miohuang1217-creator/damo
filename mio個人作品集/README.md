# Mio Huang｜個人作品集網站

這是可在 VS Code 修改的多頁靜態網站。首頁依照這次提供的參考圖，使用左右大幅照片、中間窄版標題、直排文字、柔灰底色與圓弧圖片；內容以黃紫玲的滑雪教學、颯雪品牌與影像內容實作為主。

## 開啟與預覽

1. 解壓縮程式包，於 VS Code 選「檔案 → 開啟資料夾」，選 `portfolio`。
2. 開啟 `index.html`。可使用 VS Code 的 Live Preview／Live Server 擴充功能啟動本機預覽；也可以直接用瀏覽器開啟 `index.html`，但複製功能在本機伺服器或 HTTPS 環境較穩定。
3. 從首頁點進三個案例頁、關於我和合作洽詢。每頁是獨立 HTML 網址，不是一頁式網頁。
4. 修改後按 `Ctrl + S` 儲存，重新整理預覽。

## 修改順序

1. **改文字**：打開要修改的 HTML，使用 VS Code 搜尋頁面上看到的句子並替換。`<title>` 和 `<meta name="description">` 也可以同步改。
2. **改照片**：把你的實際教學或作品照片放到 `assets/`，修改 HTML 中對應的 `src="assets/檔名.webp"`。請同時修改圖片的 `alt` 描述，並確認你有公開使用照片中人物影像的權利。
3. **改顏色**：`styles.css` 最上方的 `:root` 集中管理深綠、紙白、石灰與金棕色。這是個人作品集配色，和颯雪品牌網站分開。首頁新樣式集中在檔案後半部的 `2026 editorial layout` 註解之後。
4. **加作品**：複製一個 `work-*.html` 檔改成新案例，然後在 `index.html` 的 `.work-index` 增加對應作品入口；選單可在各頁的 `<header>` 裡修改。
5. **設定聯絡管道**：目前未提供公開 email、IG 或 LINE 連結，`contact.html` 沒有偽造聯絡方式。取得正式連結後，於 `contact.html` 的 `.contact-aside` 區塊加入連結並改掉「尚未設定」說明。

## 架設上線

這是純 HTML/CSS/JavaScript，無需資料庫或安裝依賴。把 `portfolio` 資料夾**內部**的所有 HTML、CSS、JS 和 `assets/` 上傳到靜態網站空間根目錄，確認根目錄有 `index.html`。需要能開啟多個 `.html` 頁面的主機；目前這個作品集也以私人網站提供預覽。

## 內容與影像註記

- 山景、布料、工作桌與兩位滑雪者的照片是為網站生成的**示意影像**，不是你的真實教學或創作紀錄。實際照片到位後可以替換。
- 颯雪視覺與 Logo 使用此前提供的品牌圖。
- 文案記錄了已知的學習與工作經驗。教練資格、累計教學學員數與經歷等發布前仍請本人校對。
- 洽詢表單只在瀏覽器產生可複製文字，**不會自動寄信、送出、收款或儲存資料**。公開聯絡方式需另行提供。
